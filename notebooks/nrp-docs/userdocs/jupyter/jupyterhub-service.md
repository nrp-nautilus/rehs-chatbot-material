# JupyterHub Service

## JupyterHub on Nautilus

We provide a hosted JupyterHub service running in the NRP. Using the hosted JupyterHub which is convenient if you need to quickly run your workflow and do not want to learn Kubernetes. Simply follow the above link (or https://jupyterhub-west.nrp-nautilus.io ) and use your institutional credentials to login using CILogon. Choose the hardware specs to spawn your instance. Once authenticated you can run Jupyter notebooks as usual.

Your persistent home folder initially will be limited to 5GB. If you need more, you can request it to be extended.
