# NRP-Managed vector database

The NRP provides managed vector database Milvus as a service to be used in LLMs.

You don’t need to install the operator, create the milvus instance, or create the database. All that is already done for you.

To get access to Milvus:

- Start from getting your username and password. Navigate to the Milvus password page and click the “Get milvus password” button. The link to secure page with your password will come to your email.

- You can access the Milvus databases according to the NRP group membership. Start defining collections or searching data .
